# Security policy

## Supported versions

Klaus may receive security fixes on the latest published release.

## Report a vulnerability

Do not open a public issue for a suspected vulnerability.

Use [GitHub private vulnerability reporting](https://github.com/bgigurtsis/Klaus/security/advisories/new).

Include the affected version, impact, reproduction steps, and any suggested fix.
Remove API keys, personal notes, transcripts, and page images from your report.

You may receive an acknowledgement within seven days.
The maintainer may coordinate a fix and disclosure schedule with you.
